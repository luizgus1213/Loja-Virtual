# 🛒 Loja Virtual — LG Trambicagens

Aplicação de e-commerce desenvolvida com **Next.js, React, TypeScript, Sequelize e SQLite**, criada para praticar o desenvolvimento de uma loja virtual completa.

O projeto reúne frontend, backend, autenticação, banco de dados, upload de imagens e diversas regras de negócio comuns em sistemas de e-commerce.

---

## 🚀 Funcionalidades

- Cadastro e login de usuários
- Verificação de e-mail
- Autenticação com JWT
- Cookies HTTPOnly
- Perfil do usuário
- Alteração de senha e e-mail
- Cadastro e gerenciamento de endereços
- Catálogo de produtos
- Pesquisa de produtos
- Filtros
- Página individual de produto
- Upload de imagens
- Carrinho de compras
- Favoritos
- Checkout
- Sistema de pedidos
- Histórico de pedidos
- Cancelamento de pedidos
- Compra novamente
- Avaliações de produtos
- Cupons
- Notificações
- Fluxo de pagamento
- PIX
- Painel administrativo
- Preferência de tema claro e escuro
- Integração com Firebase
- Envio de e-mails com Nodemailer
